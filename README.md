# 暖光积木屋

一个在浏览器里运行的 3D 积木搭建游戏。午后的阳光从窗户洒在木书桌上，台灯、咖啡、绿植、串灯陪着你一块一块地拼。

## 运行

双击 `start.bat`（第一次会自动安装依赖），或者：

```bash
npm install
npm run dev
```

然后在 Chrome / Edge 打开终端里显示的地址（默认 http://localhost:5173）。

## 三种模式

- **建造模式**：跟着图纸一步一步拼，共 5 张图纸（小黄鸭、苹果树、红色小汽车、海边灯塔、温馨小屋）。点击闪烁的半透明积木即可扣上。
- **自由模式**：32×32 大底板，40 多种积木、24 种颜色，支持撤销/重做、上色、吸管、拍照、导入/导出 JSON，自动保存。
- **闯关模式**：10 个小谜题——摘星星、盖高塔、复刻样品、跨河架桥、修屋顶、悬空跳台……用的积木越少星星越多。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键单击 / 右键单击 | 放置 / 拆除 |
| 左键拖动 / 右键拖动 / 滚轮 | 旋转 / 平移 / 缩放视角 |
| R | 旋转积木 |
| 1 2 3 4 | 放置 / 拆除 / 上色 / 吸管 |
| Q E / Z C | 切换积木 / 切换颜色 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| F / H | 重置视角 / 隐藏界面 |

## 技术

Three.js + Vite。积木几何全部程序化生成（按真实比例：倒角、凸点、底部空腔与管柱），房间贴图用 Canvas 绘制，音效与背景音乐用 WebAudio 实时合成，没有任何外部素材文件。

> 本项目是原创的积木搭建游戏，与 LEGO 集团无关。
